# Tanishka Rana — Portfolio

A pixel-close clone of https://iamasadshah-ibnerafi.vercel.app/ adapted for Tanishka Rana, Data Engineer.

## Quick Start

```bash
npm install
npm run dev
```

Open http://localhost:3000

---

## 📁 Files to edit

| File | What to change |
|------|---------------|
| `app/page.tsx` | Your name, bio, project details, links, FAQ answers |
| `app/layout.tsx` | Page title & meta description |
| `public/your-image.png` | **Your transparent PNG hero photo** |
| `public/your-avatar.png` | Your illustrated/anime avatar for About section |

---

## 🖼️ Photos needed

1. **Hero portrait** — transparent background PNG, named `your-image.png` → place in `public/`
2. **About avatar** — illustrated/anime style, named `your-avatar.png` → place in `public/`
3. **Project screenshots** — add paths to the `PROJECTS` array in `page.tsx`

## ✅ What's included

- `#090b14` deep navy background with starry dot texture
- Drifting ambient moon animation
- Interactive glowing cursor that follows mouse
- `"Web Apps"` → `"Data"` — massive layered background heading
- Transparent hero portrait with bottom fade mask
- Left vertical social sidebar (GitHub, LinkedIn, Email)
- Bottom pill dock navigation with active glow
- Top-right "Start a Project" CTA button
- **About** section — name reveal + avatar placeholder
- **Projects** section — card grid with tech tags + links
- **Testimonials** — animated carousel with dot controls
- **Services** — 3-column cards (Data Engineering, ML, Analytics)
- **Core Technologies** — infinite marquee scroll
- **FAQ** — animated accordion
- **CTA** — "Let's Create Something Amazing Together" with performance badge marquee + services marquee
- **Footer** with social links
